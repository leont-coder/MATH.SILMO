처음 한 번만 연결하면 됩니다

틀린 문제 사진과 실모는 비공개 저장소 에 보관됩니다. 이 앱이 거기에 읽고 쓸 수 있도록 접근 토큰을 붙여 넣어 주세요.

  1. GitHub 토큰 만들기 페이지를 엽니다.
  2. Token name에 silmo-app, Expiration은 원하는 기간을 고릅니다.
  3. Repository access에서 Only select repositories를 고르고 하나만 선택합니다.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  5. Generate token을 누르고 나온 github_pat_… 값을 복사해 아래에 붙여 넣습니다.

토큰은 이 기기의 브라우저에만 저장되고 GitHub 외의 어디로도 보내지 않습니다.
